# 福利彩票刮刮乐个人统计 PWA 设计

## 目标

构建一款个人自用、免费、手机端优先的福利彩票刮刮乐统计工具。第一版采用 PWA 手机网页版，支持 Android 和 iPhone 通过浏览器访问，在 Wi-Fi 和移动流量环境下使用。

系统重点解决三件事：

- 减少手动录入，通过摄像头扫描彩票底部条码或编号入库。
- 清楚区分彩票是否已经刮开，避免把未刮彩票误计入中奖率。
- 本地保存数据并支持备份恢复，不依赖服务器、账号或付费接口。

## 非目标

第一版不做以下功能：

- 用户登录和云同步。
- 自动联网兑奖或查询官方中奖结果。
- iOS 安装包或 Android APK。
- 自动判断中奖金额。
- 付费 OCR、短信验证码、云数据库。

这些功能可在 PWA 稳定后再评估。

## 用户流程

### 扫码入库

用户打开手机网页，点击“扫码入库”，授权摄像头后扫描彩票底部条码或编号。

扫码成功后，系统创建一条彩票记录：

- 彩票编号：来自条码或识别结果。
- 票种：自动匹配已有票种；无法匹配时由用户选择。
- 面值：来自票种配置；无法确认时由用户选择。
- 状态：默认未刮开。
- 购买日期：默认当天，可修改。

扫码失败时，用户可以手动输入或修正编号。

### 刮奖登记

用户在“未刮开”列表中选择一张彩票，刮开后登记结果：

- 未中奖：一键标记为已刮未中奖，中奖金额为 0。
- 已中奖：输入中奖金额，状态变为已中奖。
- 已兑奖：中奖后可继续标记为已兑奖。

未刮开的彩票不参与中奖率计算，但计入持有数量和总投入。

### 查看统计

首页和统计页展示个人统计结果：

- 总张数。
- 未刮开张数。
- 已刮开张数。
- 中奖张数。
- 总投入金额。
- 总中奖金额。
- 净盈亏。
- 中奖率。
- 回报率。
- 按票种统计投入、中奖、盈亏和回报率。

### 备份恢复

用户可以导出 JSON 备份文件，也可以从 JSON 备份文件恢复数据。备份包含彩票记录、票种配置和应用设置。

## 彩票状态模型

每张彩票必须且只能处于以下状态之一：

| 状态 | 含义 | 是否计入中奖率 | 是否计入投入 |
| --- | --- | --- | --- |
| 未刮开 | 已购买或已入库，但尚未刮开 | 否 | 是 |
| 已刮未中奖 | 已刮开，未中奖 | 是 | 是 |
| 已中奖 | 已刮开，中奖但未确认兑奖 | 是 | 是 |
| 已兑奖 | 已中奖并已兑奖 | 是 | 是 |

状态流转规则：

```text
未刮开 -> 已刮未中奖
未刮开 -> 已中奖
已中奖 -> 已兑奖
```

允许用户更正状态，但更正操作需要二次确认，避免误操作。

## 技术架构

### 前端

- React + Vite。
- 移动端优先布局。
- PWA manifest 和 service worker。
- 本地路由，不需要服务端渲染。

### 数据存储

- 使用 IndexedDB 保存彩票记录和票种配置。
- 使用浏览器本地存储保存轻量设置。
- 所有统计数据由本地记录实时计算，不单独持久化汇总结果。

### 扫码

扫码优先级：

1. 使用浏览器摄像头读取条码或二维码。
2. 如果无法识别条码，允许用户拍照或手动输入编号。
3. 录入后检查编号重复，重复时提示用户查看已有记录。

第一版不承诺自动识别票面所有文字，也不自动判断中奖金额。

### 部署

- 部署到支持 HTTPS 的免费静态托管平台。
- 推荐 Cloudflare Pages、GitHub Pages 或 Netlify。
- 摄像头权限依赖 HTTPS，因此正式使用不能只依赖普通 HTTP 链接。

## 错误处理

- 摄像头不可用：提示检查浏览器权限，并提供手动输入。
- 非 HTTPS 环境：提示正式使用需要 HTTPS 才能稳定调用摄像头。
- 扫码失败：允许继续扫描或手动输入。
- 编号重复：阻止重复保存，并跳转到已有记录。
- 备份文件格式错误：提示文件无效，不覆盖现有数据。
- 存储不可用：提示用户检查浏览器隐私模式或存储权限。

## 测试重点

- Android Chrome 摄像头扫码。
- iPhone Safari 摄像头扫码。
- 未刮开彩票不计入中奖率。
- 已刮未中奖、已中奖、已兑奖计入中奖率。
- 重复编号不能重复入库。
- 导出后清空数据再导入，记录数量和统计结果一致。
- 离线打开后仍能查看已保存数据。

## 第一版验收标准

- 手机浏览器可以打开 PWA。
- 可以添加到手机主屏幕。
- 可以通过摄像头录入彩票编号，失败时可以手动输入。
- 可以创建、查看、筛选和编辑彩票记录。
- 可以明确区分未刮开、已刮未中奖、已中奖、已兑奖。
- 首页和统计页能正确计算投入、中奖、盈亏、中奖率和回报率。
- 可以导出和导入 JSON 备份。
- 不需要服务器、账号、付费接口或应用商店上架。
